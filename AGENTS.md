# AGENTS.md

## Commands

```bash
# Run backend
cd src/backend && dotnet run

# Run all tests
dotnet test src/backend.tests/backend.tests.csproj

# Work from solution root
cd src && dotnet <command> src.sln
```

## Architecture

- **Backend**: ASP.NET Core (.NET 10.0) in `src/backend/`
- **Solution file**: `src/src.sln` (backend + backend.tests)
- **Database**: PostgreSQL via Supabase, accessed via both EF Core (`ApplicationDbContext`) and direct Npgsql SQL commands
- **Auth**: JWT Bearer tokens; secret via `JWT_SECRET` env var
- **Email**: Resend.com for notifications; API key via `RESEND_API_KEY`
- **Frontend**: Not yet implemented (web/mobile dirs will appear in `src/`)

## Database Quirks

- Reservation status uses PostgreSQL native enum `reservation_status` — registered in `Program.cs:108` via `MapEnum<ReservationStatus>`
- `ApplicationDbContext` maps C# `ReservaAreaComum` to `public.reservations` table (English schema names in PG, Portuguese names in C#)
- Controllers use **both** EF Core and raw Npgsql commands (see `ReservasController.cs`)
- Connection string resolution order: `ConnectionStrings:DefaultConnection` → `DATABASE_URL` / `SUPABASE_DB_URL` env var
- For local dev, use [User Secrets](https://learn.microsoft.com/aspnet/core/security/app-secrets) — never commit credentials

## Environment Variables (required)

| Variable | Purpose |
|----------|---------|
| `JWT_SECRET` | JWT signing key (throws if missing) |
| `RESEND_API_KEY` | Email service (throws if missing) |
| `DATABASE_URL` or `SUPABASE_DB_URL` | PostgreSQL connection (alternative to appsettings) |

## Testing

- **Unit tests** (no DB): `dotnet test src/backend.tests/backend.tests.csproj`
- **Integration tests** (optional): Require Docker + Testcontainers.PostgreSql, or point to a test DB via `ConnectionStrings:DefaultConnection`
- See `src/backend.tests/README.md` for integration setup

## Conventions

- Code is Portuguese (controller/Reservas, model/ReservaAreaComum, etc.)
- Documentation files (docs/) are Portuguese (Brazilian)
- CORS: "AllowAll" policy configured in `Program.cs`
- File upload limit: 100 MB (`FormOptions.MultipartBodyLengthLimit`)
- Swagger UI available at `/swagger` in Development environment

## What NOT to Do

- Don't modify `docs/CONTRIBUTION_REPORT.md` — auto-generated by GitHub Actions
- Don't commit secrets — use User Secrets or env vars
- Don't assume EF Core only — raw SQL with Npgsql is used throughout controllers
